# 04 导航 6 类 · 算法说明

## 1. 任务定义

从**导航画面截图**里读出「转向 + 距离位数」，一个模型同时给出两维信息：

| 序号 | 类别 | 含义 |
|---|---|---|
| 0 | right_3 | 右转，3 位数（如 300m） |
| 1 | right_2 | 右转，2 位数（如 50m） |
| 2 | left_3 | 左转，3 位数 |
| 3 | left_2 | 左转，2 位数 |
| 4 | uturn_3 | 掉头，3 位数 |
| 5 | uturn_2 | 掉头，2 位数 |

**方向 × 位数写在同一个检测头里**，取代了旧方案「3 类箭头模型 + OpenCV 模板匹配读数字」。
旧方案里数字只有 10~12 px，是临界值；合一之后一框两维，不再拆两个模型去对时间。

## 2. 输入契约

```
FPGA 单通道 YRG → 亮度灰度 Y = (77R + 150G + 29B) >> 8
                 → 复制 3 通道 → DIRECT 1280×720（不 letterbox）
                 → float32 NHWC 0..255，mean=0 / std=255（ONNX 首节点直接是 Conv）
```

⚠️ **必须用亮度灰度，不能用 CN 红绿保留变换** —— 导航地图底色是蓝的，
红绿变换会把整块导航屏打成黑屏。

⚠️ **训练尺度必须是缩放比 1.0**。训练用 720 方形 (0.383)，板上是 0.667，
两者不一致时实测只剩 68%。所以先在方形 1280 训练，导出时再补 720。

## 3. 训练

```bash
python train_nav6_720.py
```

- 起点：`navarrow_nomask_v2/weights/best.pt`（已验证箭头检测能力），只学"位数"这一新维度
- `epochs=120, imgsz=1280, batch=4, workers=0`
- **`fliplr=0`、`flipud=0`** —— 左右转会互换，翻转增强会直接把标签搞反
- `hsv_h/s/v=0` —— 不做色彩抖动，灰度本来就没人用色
- `mosaic=0, mixup=0, copy_paste=0` —— 导航屏是固定布局，拼接会造出假样本
- `degrees=2, translate=0.08, scale=0.20` —— 只留轻微几何抖动

## 4. 导出（两个必踩的坑）

### 坑 1：720 不是 32 的倍数，YOLOv8 架构跑不了

```
720 / 32 = 22.5 → 22
P5 上采样 22×2 = 44，而 P4 是 45 → 尺寸冲突，前向直接报错
    "Expected size 46 but got size 45"
```

**补丁：把 Concat 的所有输入插值到最大空间尺寸。** 权重完全通用（全卷积），不需要重训。

### 坑 2：必须拆 Concat（RKNN 量化必需）

不拆的话框坐标（-5.6~638）和类别分数（0~0.96）共用同一个量化 scale，
scale 被框主导，**所有类别分数被压成 0** → 模型完全失效。

```bash
python export_nav_onnx_720.py     # 导出 1280×720 精确 ONNX + 打 Concat 补丁 + 拆分
python split_onnx.py <src.onnx> <dst.onnx> 6
python conv_nav6_720_rk3568.py    # 转 RKNN
```

## 5. 板上后处理（三条硬要求）

1. **跨类别 NMS (agnostic)** —— 同一位置的 `right_3` / `right_2` 只留一个
2. **`iou=0.5`** —— 默认 0.7 会把相邻的箭头+数字框合并
3. **必须带 ROI + 尺寸过滤** —— 否则远处的小图标会被当成箭头

## 6. 实测

| 项目 | 结果 |
|---|---|
| 演示视频 2776 帧全帧回测 | FP16 / INT8 **全 100%** |
| ONNX FP32 对照 | 输出锚点数与 736 版一致（19320），cls max 0.863 vs 0.866 |
| 板端 RKNN FP16 | `nav6_720_rk3568_fp16.rknn`，8.3 MB |

## 7. 已知局限

1. **标注里有洞**：空帧中 79 帧其实有箭头（模型 0.7~0.97 检出），26 帧标成 straight 实为掉头。
   **模型是干净的，坏的是标注** —— 评估时不能拿这份标注当绝对真值。
2. **导航蓝箭头在二值图里会消失**：蓝箭头亮度约 125，低于阈值 130，二值化后变黑。
   所以导航分支必须走灰度，不能走二值。
3. **数字只有 10~12 px**，接近可辨极限。2× 放大能把准确率从 68.7% 提到 82.9%。
