# test_data_3.pcapng 图像还原与发送端检查

## 结论

抓包中三种模式均可还原为连续的 `1280x720` 图像，未发现FPGA发送端的协议、计数、字节序或模式切换错误。抓包里的不完整帧均有IPv4 Identification跳号佐证，属于报文发出后在链路、电脑网卡或抓包阶段丢失/截断，不是发送RTL跳过图像包。

## 模式切换

电脑发送了两次 `00 04`，按低字节先发解析为 `0x0400`，选择YRG；随后发送两次 `00 08`，解析为 `0x0800`，选择二值化。

- RGB565最后完整帧为1110，YRG第一完整帧为1112。
- YRG最后完整帧为1221，二值化第一完整帧为1223。
- 切换时缺少的帧号1111和1222与RTL在模式刷新时主动推进帧号的设计一致。
- 切换前后没有旧、新模式包头或像素数据拼接。

## 还原规则

- RGB565：每行两个包，每包8字节头加640个16位像素，网络字节序拼成R5/G6/B5。
- YRG/二值：每行一个包，每包8字节头加1280个8位像素。
- 8位编码中0至253表示灰度，254表示红色，255表示绿色；仅含0和253的帧判定为二值化。
